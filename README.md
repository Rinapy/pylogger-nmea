# pylogger-nmea

Логгер NMEA сообщений с поддержкой GPS и ГЛОНАСС

## Флаги командной строки

- `-p`, `--port` - COM порт для подключения (по умолчанию COM1)
- `-b`, `--baudrate` - Скорость передачи данных (по умолчанию 9600)
- `-o`, `--output` - Путь к файлу для записи логов (по умолчанию output.log)
- `-i`, `--input` - Путь к файлу для чтения данных вместо COM порта (опционально)
- `-t`, `--timeout` - Таймаут чтения данных в секундах (по умолчанию 0)
- `-d`, `--daemon` - Запуск в режиме демона (только для Linux)

## Примеры использования

1. Запуск с чтением данных из файла:

```bash
pyloggernmea -i input.log
```

2. Запуск с чтением данных из COM порта:

```bash
pyloggernmea -p COM1
```
